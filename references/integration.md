# 宿主接入

让助手读取技能根目录的 `SKILL.md`，并保留 `scripts/`、`assets/` 与 `references/` 的相对位置。宿主可用 Python 3.13+ 标准库运行脚本。先从宿主工作目录使用脚本绝对路径运行 `--help` 和 `capabilities`。配置路径以宿主当前工作目录为基准。

成功时 stdout 为 UTF-8 JSON，退出码 0。运行失败时 stderr 含脱敏错误类别，退出码 1。参数错误或缺少联网开关时退出码 2。分页和详情可能涉及多个来源请求，读取结果时同时检查组件状态与来源时间。参数与示例见[命令参考](commands.md)。
